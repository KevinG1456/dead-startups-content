# Master Assets — Homejoy

Assets to build once and reuse across all six language cuts. Do not recreate identical visual
assets six times — only text overlays and voice/subtitle tracks are language-specific.

## Shared, Reusable Across All 6 Languages
- Dollar-figure-vs-gavel cold-open/thumbnail graphic (numeral overlay swaps per language)
- Growth-chart animation (label overlay swaps per language)
- Founding/funding/lawsuits timeline graphic (label overlay swaps per language)
- "Who's classified how" contractor-vs-employee diagram (label overlay swaps per language)
- Four-lawsuit case-marker graphic (label overlay swaps per language)
- Autopsy Report Card end-graphic template (label overlay swaps per language)
- All generic B-roll/stock footage (press-clipping, empty office/cleaning-supply, blank legal
  document imagery)
- All AI-generated background/illustration/infographic images from `../ai-image-prompts.md` (none
  render real text, so none need regeneration per language)
- Thumbnail base composition/imagery (see `master-thumbnail.md` — only text layer changes)

## Language-Specific, Must Be Created Per Language
- Voice narration (HeyGen Avatar V, localized script — see `../heygen-production.md` for the
  shared performance direction; only the dialogue is localized)
- Subtitle track
- On-screen quote-card/lower-third text (translated, not just the graphic frame)
- Chapter titles and lower-third source citations
- Thumbnail text layer (composition/imagery shared, text localized)
- Title, description, tags, hashtags, SEO keywords
- Shorts, community posts, social copy

## Production Note
Build the shared graphics ONCE at a resolution/format that supports text-layer swaps in the editor
(e.g., text on a separate layer/track from the base graphic), so localizing for a new language is a
text-swap task, not a re-render task. This is a legally sensitive topic — source citation lower-
thirds must remain especially visible in every language whenever a number, date, lawsuit detail, or
claim is referenced (see `../editing-notes.md`).
