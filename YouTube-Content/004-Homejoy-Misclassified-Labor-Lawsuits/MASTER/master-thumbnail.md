# Master Thumbnail — Homejoy

The visual concept is shared across all six channels. Only the thumbnail TEXT is localized per
language — composition, colors, and imagery stay identical so the channel is visually recognizable
across markets. Full original strategy: `../thumbnails.md`.

## Shared Visual Concept (do not vary by language)
- **Core visual:** a gavel icon or simple courthouse-column silhouette next to a big "$40M" figure,
  connected by a cracking/breaking line.
- **Background:** dark, subtle legal-document texture at low opacity.
- **Lighting:** flat, even.
- **Composition:** dollar figure top-left, gavel/courthouse icon bottom-right, crack line running
  between them, title-safe space bottom third.
- **Color strategy:** white/green dollar figure, red crack line, near-black background.

## Localized Text Convention (per language — numeral/currency formatting only, concept unchanged)

| Language | Number format example | "Gone" equivalent (localize for tone, not literal) |
|---|---|---|
| English | $40M | GONE |
| German | 40 Mio. $ | WEG |
| French | 40 M$ | ENVOLÉS |
| Dutch | $40 MILJOEN | WEG |
| Norwegian | $40 MILL. | BORTE |
| Swedish | 40 MILJ. $ | BORTA |

Primary (Version B / Shock) text pattern per language, following the root package's `4 LAWSUITS.
$40M GONE.` structure:
- English: `4 LAWSUITS. $40M GONE.`
- German: `4 KLAGEN. 40 MIO. $ WEG.`
- French: `4 PROCÈS. 40 M$ ENVOLÉS.`
- Dutch: `4 RECHTSZAKEN. $40 MILJOEN WEG.`
- Norwegian: `4 SØKSMÅL. $40 MILL. BORTE.`
- Swedish: `4 STÄMNINGAR. 40 MILJ. $ BORTA.`

Each language's own `thumbnail.md` (in its folder) generates the full 3-concept/3-variation set per
the channel's standard thumbnail-strategy format, using this shared visual as Version B
(Shock/primary) and varying Versions A and C's text accordingly — see each language folder's
`thumbnail.md` for the complete localized breakdown.
