# Publishing Strategy

## Best Publishing Time
Tuesday–Thursday, 9–11am ET, consistent with channel pattern. Bench Accounting's shutdown is recent
enough (Dec 2024/Jan 2025) that "what happened to Bench Accounting" search volume may still carry some
residual urgency — no need to rush publication, but this package should perform on search relevance
sooner than the channel's older-history packages.

## Target Audience
Two overlapping audiences: (1) small-business owners who were directly affected or who use similar
bookkeeping/accounting SaaS products, and (2) this channel's core founder/operator/investor audience
studying venture debt risk. Pair distribution accordingly — this is one of the few cap-table-mechanics
packages on this channel with a real, sympathetic, non-VC-adjacent victim group worth directly
targeting in social distribution.

## Playlist
Add to "Startup Autopsies" playlist; also add to the cap-table/financing-mechanics playlist alongside
package 017 (Convoy), package 018 (Down Rounds), package 032 (Practice Fusion), package 033 (Quixey),
and package 034 (Bridge Round Death Spiral) — explicitly pair with 017 as the "same risk, different
speed" comparison.

## End Screen
Package 017 (Convoy) + most recent autopsy; subscribe element. 017 is the strongest pairing as the
channel's other venture-debt-lender story.

## Cards
Card at "The Mechanism" segment's framing card (end of Segment 6, ~8:00) linking to package 017
(Convoy) as the companion venture-debt story; card at the mid-video CTA (~10:45) linking to the
cap-table mechanics playlist; optional third card at the start of The Actual Lesson (~11:00) linking
directly to a pinned comment or community post with the sourced full-timeline graphic.

## End CTA
"If you want to see this channel's other venture-debt story, watch the Convoy video, package 017 —
same underlying risk, but that one played out over months instead of a single day. And subscribe if
you want the next autopsy in the library. One more thing before you go: were you or someone you know
