# AI Image Prompts

Simple, single-idea prompts. No rendered real text, no real logos/branding (23andMe, Nasdaq,
BreachForums, Regeneron, TTAM Research Institute, Virgin Group). No depiction of any real named
person's likeness (Anne Wojcicki or any board member) — face-led prompts describe a generic
host/avatar only. No ethnicity-specific imagery, symbols, flags, or markers in any prompt — keep
every breach-related visual abstract (DNA helix, lock, breach crack, generic data-stream texture),
never literal or specific to the Ashkenazi Jewish/Chinese-ancestry targeting detail, which is a
verbal/on-screen-text beat inside the video, not a generated-image beat.
