## LinkedIn
"A rare case study in what a responsible acquisition wind-down actually looks like — and what
happens to a product afterward when it's done right:

Parse, Inc. was founded in 2011 by Ilya Sukhar, James Yu, Tikhon Bernstam, and Kevin Lacker, part
of Y Combinator's Summer 2011 batch. Facebook acquired Parse in April 2013 for a reported ~$85
million.

In January 2016, Facebook announced it would shut down the hosted Parse.com service — but set the
actual date a full year out, and open-sourced the entire backend as 'Parse Server' the same day,
explicitly to give developers a self-hosted migration path. Parse.com shut down exactly on
schedule, January 28, 2017.

Parse Server has been independently, continuously maintained by its community ever since. As of
2026: 21,407+ GitHub stars, active development, support extending through 2028. The company's
been dead for nine years. The code it built is more actively maintained right now than most
software from companies that are still alive.
