## Long Description
Every week on this channel, we reconstruct startup outcomes using primary sources. This week:
Parse, Inc. — and the rare case where a company's death wasn't the end of the story.

Parse was founded in 2011 by Ilya Sukhar, James Yu, Tikhon Bernstam, and Kevin Lacker, part of Y
Combinator's Summer 2011 batch. It built a mobile Backend-as-a-Service platform — cloud data
storage, user logins, push notifications, and hosted custom code — at a moment when almost every
mobile app needed to build that infrastructure from scratch. (One quick note for returning
viewers: co-founder Tikhon Bernstam also co-founded Scribd, the sole survivor of the YC Summer
2006 batch we fully audited in an earlier video on this channel.)

Parse raised roughly $7-8.5 million before Facebook acquired it in April 2013 for a reported ~$85
million, explicitly positioned as Facebook's first-ever paid B2B product. Parse operated and grew
as Facebook's developer platform for about three years.

In January 2016, Facebook announced it would sunset the hosted Parse.com service — but set the
actual shutdown date a full year out, January 28, 2017. At the same moment, Facebook did something
most acquirers never do: it open-sourced the entire Parse backend as "Parse Server," a Node.js
project anyone could self-host, explicitly framed as a migration path so customers wouldn't be
stranded. Parse.com shut down exactly on the date announced a year earlier.

Here's the actual point of this video: Parse Server has been continuously, independently
maintained by a community organization — not Facebook — ever since. As of 2026, it has 21,407+
GitHub stars, active commits within the past year, and support for current Node.js versions
extending through 2028. The company has been dead for nine years. The code it built is, right
now, more actively maintained than most software from companies that are still alive.
