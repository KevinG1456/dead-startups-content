1. **Facebook Killed This Company in 2017. Its Code Has More Users Today Than It Ever Did.** —
   sharpest paradox, strongest present-tense claim, immediately sets up the "died but won" hook
2. 21,000 GitHub Stars. Zero Employees. The Company Behind This Has Been Dead for Years. — leads
   with the concrete, verifiable number before the reveal, strong curiosity gap
3. This Company Has Been Dead for 9 Years. Its Software Just Got Another Update. — clean, dated,
   plainly stated paradox
4. Acquired for $85 Million. Shut Down on Schedule. Still Running in Production Today. — three-beat
   structure covering the whole arc in one sentence
5. The Rare Startup Death Where Everybody Actually Won. — strong differentiator against this
   channel's usual catalog tone
6. This Founder Built Two YC Companies. One Survived. The Other's Code Did Instead. — strong
   returning-viewer hook via the verified Tikhon Bernstam/package-007 cross-reference
7. Facebook Bought This Startup for $85 Million, Then Shut It Down. The Code Won Anyway. — solid,
   slightly less sharp than #1
8. The Opposite of Every Other Video on This Channel: A Death That Actually Worked Out. — strong
   channel-identity hook, good for subscribers specifically
9. What Happened to Parse? The Full Story — best pure-SEO, lower CTR
10. Parse Server Explained: Why It's Still Maintained in 2026 — strong secondary search title for
    developers specifically researching Parse Server today

## Recommended Title
**"Facebook Killed This Company in 2017. Its Code Has More Users Today Than It Ever Did."**

Reasoning: leads with the sharpest version of the video's actual thesis — a real, present-tense,
verifiable claim (Parse Server's current GitHub activity genuinely exceeds anything Parse.com had
as a company) rather than a vague "still around" claim. Sets up the entire arc (death, then a
resurrection that's arguably bigger than the original) without needing the company name up front,
and works fully on a truncated mobile title. Matches the title already used in this package's
README.
