# Thumbnail Strategy

One dominant idea per thumbnail — per this channel's standing rule. Never name specific current-day
companies as Parse Server production users — only the sourced GitHub activity data.

## Thumbnail Intelligence — Winning Concept
- **Core visual:** a GitHub-style stats panel ("21,407 STARS") glowing in the foreground, with a
  faded/grayed-out company logo silhouette dissolving into dust behind it
- **Main subject:** the "code outlived the company" paradox
- **Emotion:** surprise / quiet triumph
- **Background:** dark, minimal, faint code-line texture at low opacity
- **Lighting:** single spotlight on the stats panel, the dissolving logo left dim
- **Camera angle:** N/A (graphic-led)
- **Composition:** stats panel dominant in upper two-thirds, dissolving logo lower-left, bottom-third
  title-safe space reserved
- **Props:** generic GitHub-style UI element, no real company logos or wordmarks
- **Thumbnail text:** `THE COMPANY DIED. THE CODE DIDN'T.`
- **Text placement:** bottom third, bold sans-serif, high contrast
- **Color strategy:** bright white/green stats panel (GitHub-green accent), desaturated gray
  dissolving logo, near-black background
- **Contrast strategy:** the brightness gap between the "alive" stats panel and the "dead" grayed-out
  logo communicates the entire thesis before any text is read

## Notes on What NOT to Do
- Do not render a real, identifiable photorealistic likeness of Ilya Sukhar, James Yu, Tikhon
  Bernstam, or Kevin Lacker in any thumbnail — use generic avatar/host imagery or graphic-led
  concepts only
- Do not put real Parse, Facebook, or GitHub logos/wordmarks in generated thumbnail art — build the
  visual concept generically and add any verified real branding in the editor with proper sourcing
- Do not name or depict any specific current-day company as a Parse Server user — only the sourced
  aggregate GitHub activity numbers are confirmed
