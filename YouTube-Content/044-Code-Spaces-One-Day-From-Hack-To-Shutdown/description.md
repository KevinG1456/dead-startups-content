# Video Description

## Main Description (YouTube, long-form)

A hacker got into this company's cloud account, left a ransom demand, and asked for money to stop a
DDoS attack. The company said no — and tried to lock the attacker out by changing its passwords.

It didn't work. The attacker had already planted a second way back in. And when they got back in,
they didn't just delete the company's data. They deleted its backups too — because both lived in the
same account.

June 17, 2014: the attack begins. June 18, 2014: Code Spaces announces it's closing for good.

This is the fastest company death on this channel — and the cause fits in one sentence: a backup
that can be deleted by the same person, at the same time, as the original isn't really a backup.

Honesty note: very little is publicly known about Code Spaces before this incident — no founder
name, funding history, or customer count has ever been confirmed. This video covers what's actually
documented: the attack, the failed recovery, and the shutdown, reconstructed from contemporaneous
security-industry reporting and the company's own final public statement.
