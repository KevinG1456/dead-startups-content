# Master Thumbnail — Sprig

The visual concept is shared across all six channels. Only the thumbnail TEXT is localized per
language — composition, colors, and imagery stay identical so the channel is visually recognizable
across markets.

## Shared Visual Concept (do not vary by language)
- **Core visual:** a large "$22M" figure in green, with a red "STILL DIED" stamp overlapping it
  at an angle.
- **Background:** dark, minimal.
- **Lighting:** flat, even, single spotlight on the central figure.
- **Composition:** big number centered, stamp overlapping at an angle, title-safe space bottom
  third.
- **Color strategy:** green dollar figure, red stamp accent, near-black background.

## Localized Text Convention (per language — numeral/currency formatting only, concept unchanged)

| Language | Number format example | "Still Died" equivalent (localize for tone, not literal) |
|---|---|---|
| English | $22M | STILL DIED |
| German | 22 Mio. $ | TROTZDEM PLEITE |
| French | 22 M$ | QUAND MÊME MORT |
| Dutch | $22 MILJOEN | TOCH FAILLIET |
| Norwegian | $22 MILL. | GIKK KONKURS ALLIKEVEL |
| Swedish | 22 MILJ. $ | GICK ÄNDÅ KONKURS |

Each language's own `thumbnail.md` (in its folder) generates the full 3-concept/3-variation set
per the channel's standard thumbnail-strategy format, using this shared visual as Version B
(Shock/primary) and varying Versions A and C's text accordingly — see each language folder's
`thumbnail.md` for the complete localized breakdown.
