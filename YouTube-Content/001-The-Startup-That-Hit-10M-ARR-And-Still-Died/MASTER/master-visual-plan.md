# Master Visual Plan — Sprig

Shared across all six languages. Only on-screen TEXT is localized (numbers formatted per
language convention, lower-third labels translated) — the visual concepts, compositions, and
shot list below do not change by language.

## Core Recurring Graphics (build once, reuse in every language cut with localized text overlays)
1. **Revenue-vs-loss contrast graphic** ($22M/year vs -$850K/month) — cold open and recurring.
2. **Funding timeline** — Series A → Series B → total raised, climbing left to right.
3. **Run-rate + quote card** — Biyani's hedge quote, displayed as on-screen text as it's spoken.
4. **"Who bears the cost" diagram** — Sprig's owned-kitchen model vs. a typical restaurant-
   marketplace model, side by side, showing where financial risk sits in each.
5. **Growth-rate graph** — flips from +2% to -2% at the Uber Eats trigger moment; keep visible in
   a corner through Segments 7–8.
6. **Shutdown/headcount graphic** — clearly visually distinguishes "peak operational headcount
   (1,300+)" from "headcount at shutdown (~200)" — e.g., two separate labeled bars, not one
   number replacing another.
7. **Founder quote cards** — Biyani's hindsight quotes, typed on screen as read aloud, always
   paired with the required contextual caption (see master-research.md).
8. **Autopsy Report Card** — end-graphic template (run rate, burn, cause of death, verdict) —
   channel-signature asset, reused across languages with translated labels only.

## B-Roll / Stock Requirements
- Generic commercial-kitchen imagery (no real Sprig branding/logos — this is a defunct company,
  do not fabricate its real UI/branding without rights clearance).
- Generic food-delivery-bag-on-doorstep imagery.
- Generic laptop/dashboard imagery for the "run rate" and "growth rate" segments (no real
  interface rendered).

## AI Image Prompts (language-neutral — reuse across all six cuts)
See `../ai-image-prompts.md` for the full prompt set (thumbnail, background, illustration,
infographic, scene-artwork prompts). None of these prompts render real text or real branding, so
they require no localization — only the text overlaid in post-production changes per language.

## Animation Style
- Text-reveal (not fade) for all key numbers and quotes, in every language.
- Ken Burns pan/zoom on static generic imagery.
- Quote cards type on screen in sync with the localized narration's pacing (timing will vary
  slightly by language — see `master-editing-timeline.md`).
