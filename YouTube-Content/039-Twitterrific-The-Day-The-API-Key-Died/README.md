# 039 — This App Invented the Word "Tweet" and the Bluebird Logo. Twitter Killed It With Zero Warning, in Hours.

**Package status:** Filled in and sourced — built around Twitterrific and The Iconfactory's fully
documented public history (Iconfactory's own blog, Wikipedia, TechCrunch, 9to5Mac — full citations in
`sources-log.txt`). Ninth title on the channel sourced from the "dead-saas-30-Content Titles new-
video-ideas.md" batch (Cluster 2, idea #14: "The integration that was the whole company"). Titles #12
and #13 from the same batch were skipped for lack of a real, verifiable anchor (see
`project_channel_overview.md` memory).

**Important departure from this channel's usual profile:** The Iconfactory is a bootstrapped,
independent software studio (founded 1996), not a venture-funded startup. This is a deliberate
exception, justified by how precisely this real story matches this specific title's pattern and by its
unique historical significance — flag this honestly in every file rather than implying VC funding.

**The real case:** Twitterrific, built by The Iconfactory's Craig Hockenberry, launched January 15,
2007, as the first-ever Twitter desktop client — built almost overnight after the idea struck in
December 2006. Twitter's own developer suggested Hockenberry use the word "tweet" instead of "twit";
the term stuck and entered the dictionary. Iconfactory designer David Lanham created the app's cheerful
bluebird mascot, "Ollie," which Twitter itself later adopted as its own platform logo. Twitterrific ran
for fifteen years. On January 12-13, 2023, without any warning, Twitter — under new owner Elon Musk —
revoked API access for third-party client apps. Twitterrific broke instantly. Twitter stayed silent for
five days before offering a vague explanation. On January 19, 2023, Iconfactory formally announced
Twitterrific's discontinuation, writing that its "sudden and undignified demise is due to an
unannounced and undocumented policy change by an increasingly capricious Twitter." A separate, unrelated
company, Tapbots, lost its own Twitter client, Tweetbot, to the exact same cutoff the same day.

**Framing requirement:** No fraud or misconduct framing toward Twitter/X or Elon Musk — this is a
platform-power and dependency-risk story, told through real, sourced facts about a policy decision and
its consequences. Twitterrific's role in coining "tweet" and creating the bluebird icon is real and
well-documented cultural/historical fact, not a formal trademark claim.
