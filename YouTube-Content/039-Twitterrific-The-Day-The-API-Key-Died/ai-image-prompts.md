# AI Image Prompts

Simple, single-idea prompts. No rendered real text, no real logos/branding (Twitterrific, Twitter/X,
Tweetbot, Iconfactory, Tapbots), and no photorealistic likeness of any real named person (Craig
Hockenberry, Gedeon Maheux, David Lanham, Elon Musk) — add verified text/branding and any real
archival photography in the editor with proper sourcing, not generated. Never use the real Twitter/X
bluebird logo — use a generic bird silhouette shape instead throughout.

## Thumbnail Prompts
**Prompt A (recommended primary):** "YouTube thumbnail, a generic cheerful bluebird silhouette icon
centered in frame, a visible red crack running through the middle, a small red stamp mark overlaid,
dark background with faint app-icon-grid texture, single spotlight on the crack, high contrast, empty
space at bottom third for title text, no readable logos or brand names, 16:9 --ar 16:9"

**Prompt B:** "YouTube thumbnail, a large bold typographic word treatment, one letter visibly
glitching and breaking apart into fragments, dark background, single spotlight on the glitching
letter, high contrast, empty space at bottom third for title text, no readable text beyond the
glitch effect itself, 16:9 --ar 16:9"

**Prompt C:** "YouTube thumbnail, tight three-quarter crop portrait of a generic host avatar,
dramatic single top-down light, serious analytical expression, dark background, small red
document/chart icon tag graphic in the corner, photorealistic, cinematic, high contrast, not a real
identifiable person, 16:9 --ar 16:9"
