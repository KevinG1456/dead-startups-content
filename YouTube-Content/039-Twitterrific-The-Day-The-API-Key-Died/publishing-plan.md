# Publishing Strategy

## Best Publishing Time
Tuesday–Thursday, 9–11am ET, consistent with channel pattern. Strong nostalgia pull for early Twitter
culture plus ongoing relevance to platform-power discourse gives this package above-average general-
audience potential — no urgency premium, hold for the best day/time slot.

## Target Audience
Broad crossover: developers/founders building on major platforms (core dependency-risk audience),
general tech-nostalgia audience with memories of early Twitter/Twitterrific/Tweetbot, and viewers
interested in tech-history word-origin trivia (the "tweet" story specifically has strong shareability
beyond this channel's usual niche).

## Playlist
Add to "Startup Autopsies" playlist; also add to the same platform-dependency playlist as package 008
(Meerkat/Viddy) — explicitly label this as a different era/mechanism of the same underlying risk.

## End Screen
Package 008 (Meerkat/Viddy) + most recent autopsy; subscribe element. 008 is the strongest pairing as
the channel's other platform-dependency story.

## Cards
Card at the "TWEETBOT — SAME DAY, DIFFERENT COMPANY" title card (end of Segment 9, ~9:00) linking to
package 008 as the companion platform-dependency story; card at the mid-video CTA (~8:45) linking to
the platform-dependency playlist; optional third card at the start of The Actual Lesson (~9:00) linking
directly to a pinned comment or community post with the sourced full-arc timeline graphic.

## End CTA
"If you want the other platform-dependency story on this channel, watch the Meerkat video, package
008. And subscribe if you want the next autopsy in the library. One more thing before you go: did you
ever use Twitterrific or Tweetbot, and did you know the word 'tweet' had a documented origin story
before this video? Tell me in the comments."
