## Complete Viral Script (Main Cut)

**Target length:** 10–13 minutes

### Cold Open (0:00–0:20)
- VO: "When does pivoting stop being adaptive and start being avoidance?"
- Visual: looping arrow path animates in, circling repeatedly, ending at a simple tombstone icon with a heavy SFX hit
- Pattern Interrupt: hard cut to silence, white text on black: "This happened five times. Here's the pattern."

### What Makes a Pivot Good vs. Bad (0:20–1:30)
- VO addresses the obvious counterpoint immediately: Slack, YouTube, Twitter, and Instagram all pivoted successfully — pivoting itself isn't the problem
- Introduce the core distinction: a good pivot is thesis-driven, tests a specific new hypothesis, and has a clear kill criterion; a bad pivot is reactive, avoids a hard truth about the original idea, and repeats without a clear thesis
- Preview the 5-case structure with the numbered case-card graphic

### Case 1 (1:30–3:00)
- Company, pivot sequence, what happened, sourced outcome
- Visual: case-card graphic "1 of 5," pivot-sequence loop animation, relevant B-roll/document evidence

### Case 2 (3:00–4:30)
- Same structure, different company

### Case 3 (4:30–6:00)
- Same structure, different company
- Mid-video CTA (~6:00): "If you're weighing a pivot decision right now, stick around — the framework at the end is built exactly for this. Subscribe for a new autopsy every week."

### Case 4 (6:00–7:30)
- Same structure, different company

### Case 5 (7:30–9:00)
- Same structure, different company
- Slightly slower pacing on this final case to let it land before the synthesis section

### The Framework (9:00–10:30)
- Synthesize the pattern across all 5 cases into a concrete, practical framework: does this pivot have a specific, testable thesis? Does it have a clear timeline and kill criterion? Is it addressing a real signal from the market, or avoiding an uncomfortable one about the current product?
- Visual: framework graphic builds progressively, contrasted directly against the successful-pivot counterexamples from the opening

### Final CTA + Outro (10:30–11:30)
- VO: recap the one-sentence lesson — pivoting is a tool, not a strategy in itself; the thesis behind the pivot matters more than the act of pivoting
- "Subscribe — I'm building a full library of these"
- Engagement prompt: "If you're mid-pivot, where are you in this framework? Tell me in the comments."
- End screen: two related autopsies + subscribe

## Alternative Scripts

### Script Version A — Data-First / Analyst Style
Opens directly on the finished framework graphic, then works backward through the 5 cases as supporting evidence for each framework point. Measured, graphics-forward.

### Script Version B — Narrative / Documentary Style
Leads with the most emotionally resonant single case in full, then rapid-fires the remaining 4 as a montage before returning to the framework. Cinematic, uneven pacing intentionally used for contrast.

### Script Version C — Fast-Cut / Listicle Style
Structured as a strict countdown ("5 companies that pivoted too many times"), each case capped at 60–75 seconds, built for maximum Shorts-extraction — nearly identical to the main cut but tighter per-segment.

## Audience Retention Optimization
- **Drop-off risk:** case 3–4 transition, if segments start to feel repetitive in structure
- **Fix:** vary the visual treatment slightly per case (different B-roll type, different pivot-sequence loop shape) even while keeping the case-card format consistent
- **Faster pacing opportunity:** any case with a thin pivot history should be trimmed rather than padded
- **Curiosity increase opportunity:** tease the framework explicitly during Case 1 ("keep this one in mind for the framework at the end")
- **Recommended visual change:** show a partial, blurred version of the framework graphic in the cold open, fully revealed only at the end
