# Master Visual Plan — Quibi

Shared across all six languages. Only on-screen TEXT is localized — visual concepts, compositions,
and shot list do not change by language.

## Core Recurring Graphics
1. **Full-zero dollar figure animation** ($1,750,000,000 counting up) — cold open, snapping to a
   red "SHUT DOWN" stamp.
2. **Horizontal decision-timeline graphic** — spans launch day to shutdown day, with rejected-
   pivot markers appearing chronologically. This is the video's core structural/visual spine —
   build once, reuse with translated labels in every language.
3. **Missing-feature reveal graphic** — TV casting / free tier / social sharing icons, each
   marked with when it was requested vs. when (if ever) it shipped.
4. **Shutdown headline + asset-sale graphic** (Roku deal).
5. **Autopsy Report Card** — end-graphic template, reused across languages with translated labels.

## B-Roll / Stock Requirements
- Generic press-clipping-style headline graphics (no real verbatim outlet UI without rights
  clearance).
- Generic smartphone-streaming-app-interface imagery (no real Quibi UI rendered).
- Generic empty media-office imagery for The Fall segment.

## Animation Style
- Text-reveal (not fade) for all key numbers and dates, in every language.
- Ken Burns pan/zoom on static press photos/archival stills.
- Ticking-clock SFX under the timeline graphic in every language's edit.
