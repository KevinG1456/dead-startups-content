# Master Assets — Quibi

Assets to build once and reuse across all six language cuts. Only text overlays, voice, and
subtitle tracks are language-specific.

## Shared, Reusable Across All 6 Languages
- Full-zero dollar figure countup animation (numeral overlay swaps per language)
- Decision-timeline graphic (label overlay swaps per language)
- Missing-feature reveal graphic (label overlay swaps per language)
- Shutdown/Roku-asset-sale graphic (label overlay swaps per language)
- Autopsy Report Card end-graphic template (label overlay swaps per language)
- All generic B-roll/stock footage (press-clipping style, smartphone-app imagery, empty office)
- All AI-generated background/illustration/infographic images from `../ai-image-prompts.md`
- Thumbnail base composition/imagery (see `master-thumbnail.md`)

## Language-Specific, Must Be Created Per Language
- Voice narration (HeyGen Avatar V, localized script)
- Subtitle track
- On-screen lower-third labels and chapter titles
- Thumbnail text layer
- Title, description, tags, hashtags, SEO keywords
- Shorts, community posts, social copy

## Production Note
Build shared graphics with text on a separate layer/track so localizing for a new language is a
text-swap task, not a re-render task.
