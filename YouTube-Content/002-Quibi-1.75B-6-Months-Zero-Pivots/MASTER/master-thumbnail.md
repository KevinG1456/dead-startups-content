# Master Thumbnail — Quibi

Shared visual concept across all six channels. Only thumbnail TEXT is localized.

## Shared Visual Concept (do not vary by language)
- **Core visual:** giant "$1.75B" in bold white/green text with a stopwatch or countdown graphic
  next to it reading "6 MONTHS."
- **Background:** dark, subtle red gradient creeping in from the edges.
- **Composition:** number top-left, countdown/stopwatch bottom-right, title-safe space bottom
  third.
- **Color strategy:** white/green number against near-black, red accents signal loss.

## Localized Text Convention (per language — numeral/currency formatting only, concept unchanged)

| Language | Number format example | "Gone" equivalent (localize for tone) |
|---|---|---|
| English | $1.75B. 6 MONTHS. | GONE |
| German | 1,75 Mrd. $. 6 MONATE. | WEG |
| French | 1,75 Md$. 6 MOIS. | DISPARU |
| Dutch | $1,75 MILJARD. 6 MAANDEN. | WEG |
| Norwegian | $1,75 MRD. 6 MÅNEDER. | BORTE |
| Swedish | 1,75 MDR $. 6 MÅNADER. | BORTA |

Each language's own `thumbnail.md` generates the full 3-concept set per the channel's standard
format, using this shared visual as Version B (Shock/primary).
